My old site cost me a domain bill every year and hadn't changed since 2023. This one runs on GitHub Pages, which is free, and GitHub Actions rebuilds it every day.

The ScoreGen entry has a small demo: sing a note and it shows up on a staff. It's a tiny browser version of the pitch-detection step from our capstone.

This log fills itself in. Releases and pushes from my public repos show up on their own, and when I want to write something I open a GitHub issue with the `log` label.
