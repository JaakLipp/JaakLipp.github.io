My old site cost me a domain bill every year and hadn't changed since 2023. This one runs on GitHub Pages, so it's free, and GitHub Actions rebuilds it every day.

Some details:

- **The ScoreGen card has a small demo.** Sing a note and it lands on the staff. It's a tiny browser version of the pitch-detection step from our capstone.
- **Press `Ctrl` + `K`** anywhere to open the command palette.
- **The log fills itself in.** Releases and pushes from my public repos show up automatically. To write something, I open a GitHub issue with the `log` label and it becomes a post like this one.
