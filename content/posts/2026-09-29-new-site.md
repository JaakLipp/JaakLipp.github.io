My old site cost me a domain bill every year and hadn't changed since 2023. This one is hosted on GitHub Pages, so it's free, and GitHub Actions rebuilds it every day.

A few things worth trying:

- **Sing to the homepage.** The pitch detector at the top uses YIN, the same family of algorithm we used in ScoreGen's DSP engine. Every note you hold lands on the staff in the ScoreGen card.
- **Name that note.** A short ear test that comes out of my perfect-pitch research.
- **Press `Ctrl` + `K`** anywhere to open the command palette.

This log fills itself in. Releases and pushes from my public repos show up automatically. When I want to write something, I open a GitHub issue with the `log` label and it becomes a post like this one.
