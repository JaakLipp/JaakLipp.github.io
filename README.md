# jaaklipp.github.io

Source for my portfolio, [jaaklipp.github.io](https://jaaklipp.github.io).

Plain HTML, CSS and JavaScript. A small Node script builds the page from the files in `content/`, and GitHub Actions deploys it to GitHub Pages.

```bash
npm run dev    # build and serve at http://localhost:8080
```

```
content/   profile, projects and experience data
src/       page template, styles, scripts and assets
scripts/   build and local server
```
